| `AI.list` / `Proxy.list` / `Direct.list` / `Global.list` / `IPTV.list` / `Private.list` / `Download.list` | 分流规则集（被 ini 以 raw 链接引用） |
| `Clash-Reyan-New.ini` | subconverter 模板（两台路由器订阅转换用的唯一模板） |
| [`docs/40-TROUBLESHOOTING.md`](docs/40-TROUBLESHOOTING.md) | 排查记录（含「共用域名 + GeoDNS ⇒ 分流规则不生效」通用规律） |
